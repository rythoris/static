# Static

Static is simple and experimental site generator that is build on top of the
[tera](https://keats.github.io/tera/) template engine and
[markdown-rs](https://github.com/wooorm/markdown-rs). Static is build with UNIX
philosophy in mind, thus there is no configuration or sophisticated build
system, only a simple executable that builds HTML files from markdown content
and your base templates.

## Installation

Using [`cargo install`](https://doc.rust-lang.org/cargo/commands/cargo-install.html):
```bash
cargo install --git https://github.com/rythoris/static.git
```
